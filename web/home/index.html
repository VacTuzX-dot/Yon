Yon (โยน, “to toss”) is a free, open-source app that sends files and folders between your Macs, Windows PCs and phones, like AirDrop for every device you own. Straight from one device to the other, encrypted, with no account and no cloud.

What it does

  • Finds devices on your Wi-Fi. Pick one, pick files or a whole folder, and the other side chooses Accept or Decline.
  • Any file, any size. Large files stream, so a 1 GB video uses a few MB of memory, and every file is checked with SHA-256 when it arrives.
  • Phones too, no app store. Scan a QR code once, add the page to your Home Screen, and send photos from your phone to your computer.
  • From anywhere, if you want. Turn on Reach from anywhere and your phone reaches your computer on any network, through a relay that only ever sees encrypted data.

Download

Download Yon __VERSION__ for your Mac or PC. Yon updates itself after that.

On a Mac you can also install from Terminal, which skips the first-open warning:

curl -fsSL https://raw.githubusercontent.com/VacTuzX-dot/Yon/main/install.sh | bash

The builds aren't notarized by Apple or signed for Windows yet, so the first open from a download asks you to confirm: macOS, Privacy & Security → Open Anyway; Windows, More info → Run anyway.

Questions

Is Yon free?
Yes. Yon is free and open source under the MIT license. There is no account, no subscription and no ads.
Does Yon upload my files to the cloud?
No. Files go straight from one device to the other over an encrypted TLS 1.3 connection on your network. Only if you turn on Reach from anywhere does a relay pass on data, and it only ever sees it encrypted.
Which systems does Yon run on?
macOS on Apple Silicon and Intel, and Windows on x64 and ARM64. Phones use the Yon Link web page, so there is no app to install on iPhone or Android.
How do I send a file from my phone to my computer?
Open Settings, Phones, Pair a phone on the computer, scan the QR code with the phone's camera and add the page to your Home Screen. Then pick photos or files from the Yon icon.
Can I send a whole folder?
Yes. Drop a folder on a device or choose Send a folder. It arrives as a new folder with everything inside, and the other side sees the file list before accepting.
Is Yon an AirDrop alternative for Windows?
It does the same job across systems: nearby devices show up automatically, you pick one and send. It works between Macs, Windows PCs and phones, which AirDrop doesn't.

Pair a phone

  1. On the computer, open Settings → Phones → Pair a phone.
  2. Scan the QR code with the phone's camera and open the link.
  3. Add the page to your Home Screen. From then on, tap the Yon icon to send.

How it stays private

  • Every install has its own Ed25519 key, and computers talk over mutual TLS 1.3. The receiver sees the sender's device code, not just a name that could be faked.
  • Nothing is written until you accept, and file names are cleaned so they can't escape the save folder or overwrite anything.
  • Phones encrypt every request with their pairing key (ChaCha20-Poly1305). The relay forwards sealed data and stores nothing.
  • Updates are signed and checked against a key built into the app.

Details, trade-offs and what's still missing are in the README and the threat models.
