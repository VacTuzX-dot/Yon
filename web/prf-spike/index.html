Yon PRF test

Checks that a passkey gives the same secret after this Home Screen icon is deleted. Nothing leaves this phone.

  1. Share → Add to Home Screen, open it from the icon.
  2. Tap Create passkey, then Read.
  3. Delete the icon, add it again, open it, tap Read.
  4. The two read fingerprints should match. Tap Copy and send the log.
  5. Afterwards delete the passkey “Yon PRF test - delete me” in Passwords.
